# frontend

Dashboard and verification portal for Memoris.

Planned views:
- **Agent explorer** — list of agents and their memory activity
- **Memory explorer** — browse individual memory objects and their receipts
- **Verification portal** — paste a Memoris receipt, confirm it's valid against Shelby's underlying proof
- **Analytics** — memory volume, verification status, agent activity over time

Built with Next.js, React, Tailwind, and TypeScript.

**Status:** not yet implemented — architecture in progress.
